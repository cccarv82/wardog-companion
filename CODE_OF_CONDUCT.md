# Code of Conduct

We want WARDOG Companion to be a welcoming place to collaborate, regardless of experience, background or identity.

- Be respectful, specific and constructive. Critique ideas and code without attacking people.
- Make space for newcomers and different perspectives. Assume good intent while taking feedback seriously.
- Do not harass, discriminate, threaten, publish private information or make unwanted personal or sexual comments.
- Keep discussions relevant. Do not post spam, cheats, credential requests or instructions to compromise other players.

This policy applies to project issues, pull requests and other project-managed spaces. Maintainers may edit or remove content, close discussions, or restrict participation when needed. They should explain moderation decisions where doing so does not compromise privacy or safety.

For ordinary moderation concerns, contact the maintainer through the public contact options on [their GitHub profile](https://github.com/cccarv82). Do not publish private information in an issue. If no suitable private channel is available, request one without including sensitive details. Security vulnerabilities have a separate [reporting policy](SECURITY.md).
